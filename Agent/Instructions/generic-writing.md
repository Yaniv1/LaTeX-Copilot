# Generic Scientific-Writing Instructions

Write precise, evidence-based scholarly prose with a clear argumentative
structure. Separate established facts, measured results, interpretation,
limitations, and proposed future work. Do not invent citations, measurements,
participants, datasets, or implementation details.

Develop each section around a purpose and claim rather than assembling
disconnected facts. Explain why evidence supports a conclusion and identify
credible alternative interpretations. Define specialized terms before relying
on them, maintain notation consistently, and avoid inflated claims.

Prefer coherent paragraphs over bullet lists unless the target venue or
author explicitly requires a list. Tables and figures must have a stated
analytical purpose, readable labels, source provenance, and a discussion in
the text. Every external claim that is not common knowledge requires a
traceable reference.

Preserve the selected paper's template and venue constraints. Compile after
each coherent revision, resolve errors and undefined references, and report
page count and material warnings. Never publish, synchronize, commit, or push
without the authorization required by the selected workflow.

If no template is requested use the default template under Paper/templates/paper-template.sty.
